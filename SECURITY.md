# Security Policy

## Project status

VIRTUE WISE is in an early planning/prototype stage. Supported versions and a formal security response SLA have not yet been established.

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, secrets, personal information, or sensitive user data in public issues.

Use GitHub's **Report a vulnerability** feature in the repository's Security tab if it is enabled. Otherwise, contact the maintainers through the private contact method listed on the GitHub organization profile and request a secure reporting channel.

Please include, when safe to do so:

- A concise description and potential impact
- Steps to reproduce or a proof of concept
- Affected commit, branch, or component
- Any suggested mitigation

We will acknowledge reports as soon as practical, investigate in good faith, and coordinate disclosure with the reporter. Please allow time for a fix before public disclosure.

## Security and privacy priorities

The project aims to minimize sensitive data collection, keep permissions explicit, protect credentials, document data flows, and make user data export and deletion possible. These are design goals, not a claim that the current project has already implemented all such controls.
